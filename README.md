# E-commerce Order Analysis using SQL

## Project Overview
This project focuses on analyzing e-commerce customer orders and sales data using PostgreSQL. It demonstrates SQL skills including table creation, joins, aggregate functions, GROUP BY, HAVING, and subqueries.

## Technologies Used
- PostgreSQL
- SQL
- pgAdmin 4

## Database Structure
The project contains three tables:

1. **Customers** – Customer details and city.
2. **Products** – Product names and prices.
3. **Orders** – Customer orders, quantities, and order dates.

## SQL Concepts Covered
- CREATE TABLE
- INSERT INTO
- INNER JOIN
- SUM()
- GROUP BY
- HAVING
- ORDER BY

## Business Questions
1. Display customer order details.
2. Calculate total spending per customer.
3. Identify customers who spent more than ₹30,000.

## Project Files
- `schema.sql` – Creates database tables.
- `data.sql` – Inserts sample data.
- `analysis.sql` – Contains SQL analysis queries.

## How to Run
1. Create a PostgreSQL database named `ecommerce_db`.
2. Execute `schema.sql`.
3. Execute `data.sql`.
4. Execute queries from `analysis.sql`.
